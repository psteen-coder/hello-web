About hello-web

hello-web is a small static site. The home page greets you by time of day, shows a live clock with your timezone, and can remember a name, a 12- or 24-hour clock preference, and a light or dark theme (following the OS until you choose).

There is also this about page and a 404 page, all sharing one stylesheet with keyboard focus styles, reduced-motion support, a mobile breakpoint and print styles. Preferences stay in your browser; nothing is sent anywhere.

The project is MIT-licensed. Development uses Prettier, Stylelint, html-validate, markdownlint, an offline link checker and Playwright smoke tests, all run in GitHub Actions on every pull request.

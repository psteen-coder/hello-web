# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [Unreleased]

### Added

- Local preferences: light/dark theme (defaults to the OS scheme), 12/24-hour
  clock, visitor name in the greeting, and a Reset preferences button
- Live clock with timezone short name, time-of-day greeting, and copy button
- About and 404 pages, favicon, footer, focus and print styles, reduced-motion
  support, and a mobile breakpoint
- Dev tooling: Prettier, Stylelint, html-validate, markdownlint, lychee
  (offline), Playwright smoke and feature tests, a tiny local server, and
  matching GitHub Actions CI

# Security policy

## Supported versions

hello-web is a static site without versioned releases. Only the latest code on `main` is supported.

## Reporting a vulnerability

Please do not report security issues in public issues or pull requests.

- Preferred: use GitHub's private vulnerability reporting ("Report a vulnerability" under the repository's Security tab), if it is enabled for this repository.
- Otherwise, contact: **[SECURITY CONTACT PLACEHOLDER: P S to fill in]**

Include a description, steps to reproduce, and the affected page or file. You can expect an acknowledgement as soon as the maintainer is able to respond.
